# 关于我 / About Me

我是 **年下牧马**。这里是我的博客，用来记录代码、折腾和日常。

主站在 [nianxiamuma.github.io/portfolio](https://nianxiamuma.github.io/portfolio/)，那边放着收藏、游戏、唱机和一些零散的小工具；文章搬到了这里，是因为想要一套能长期写下去的东西——归档、标签、全文搜索、RSS，该有的都有。

## 🛠️ 关于本站

本站用 **Astro** 构建，主题是 Firefly。Firefly 基于 [Fuwari](https://github.com/saicaca/fuwari) 二次开发，功能完整、开箱可用，省掉了从零搭博客的时间。

它和主站同仓部署：主站是 Vite 构建的 React 单页应用，博客是独立构建的静态站，CI 里先建主站再建博客，最后把博客产物并进 `dist/blog/`。所以两者共享同一个域名和同一个 Pages 部署流程。

**⭐ Firefly 开源地址：[https://github.com/CuteLeaf/Firefly](https://github.com/CuteLeaf/Firefly)**

**⭐ Fuwari 开源地址：[https://github.com/saicaca/fuwari](https://github.com/saicaca/fuwari)**
